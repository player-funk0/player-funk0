## Philosophy

- **Offline-first is a constraint, not a limitation.** If an app needs the internet to be useful, I've usually made a design mistake.
- **On-device AI over cloud AI.** Gemma, hand-derived NumPy attention, TextRank — inference should happen where the data lives. Serene Focus doesn't even declare the `INTERNET` permission.
- **Ship something real, then make it rigorous.** I build fast prototypes first, then go back and add the math, the tests, and the privacy guarantees.
- **Resource constraints breed better architecture.** I build on modest hardware — it forces lean code instead of throwing compute at problems.
